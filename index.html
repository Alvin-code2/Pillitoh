Practical reflection ranges
  • Nurses / Midwives (NCK): ~48 hrs
  • Medical Officers (KMPDC): same day–3 days
  • Consultants / Specialists: immediate–3 days
  • Consultant Physicians: immediate–3 days
  • Clinical Officers / CO Anaesthetists: 1–7 days
  • COHO: 1–7 days
  • Pharmacists / Pharm Techs, token-based: same day–7 days
  • Pharmacists / Pharm Techs, self-reported: up to 2 months
  • Physiotherapists: 2–14 days
  • Dental Officers / Dentists: immediate–3 days
  • HDN: ~48 hrs
  • Morticians / HDCM / Orthopedic & Trauma: 2–14 days

Ranges are practical estimates, not guaranteed regulator SLAs. Delayed verification, incorrect details, system downtime or token/submission issues can affect reflection time.
